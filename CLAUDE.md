# Project rules

- **Never store company-related information in code or Markdown files.** That includes company
  names, server/host names, domains, Key Vault names, database names, login/group names, role
  names and environment codes from any real organization. Examples use generic placeholders
  (`my-server.database.windows.net`, `MyAppDb`, `DEV`/`TEST`/`STAGE`/`PROD`, `.\Profiles\example.json`).

See `PSGALLERY.md` for the remaining PowerShell Gallery readiness work.
